# Amendment discipline

Status: approved — 2026-08-02 · ported verbatim from doc 08 §3 of the graph-engine
design set — the upstream design record.

This design changes by the same mechanism it prescribes: a proposal (retro issue or
operator request in conversation) → an edit to one versioned file → normal review. Two
standing rules: an amendment that moves work across the AC boundary (model ↔ engine)
must cite evidence per the upstream evidence standard (01 §3), and an amendment that
adds manual upkeep for the developer violates T9 (zero-touch) on its face.

Decisions D1–D16 live upstream; cite by number.
